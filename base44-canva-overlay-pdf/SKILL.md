## מתי להשתמש בגישה הזאת (ולא ב-html2canvas)

| צריך | גישה |
|------|------|
| PDF פשוט מ-HTML מרונדר | `hebrew-pdf` (html2canvas) |
| **שחזור מדויק של עיצוב Canva/PSD רב-עמודי + הזרקת נתונים** | **הסקיל הזה (רקע+overlay)** |

html2canvas לא משחזר עיצוב Canva מורכב (פונטים, אפקטים, פריסה). הפתרון: לייצא
מ-Canva כל עמוד כ-JPEG, להטמיע כרקע מלא של עמוד A4, ולצייר מעל רק את הטקסט הדינמי.

## הארכיטקטורה

```
Canva (27 עמודים) ──export──> 27 × JPEG (110 DPI, q82, ~5MB סה"כ)
        │
        ▼
העלאה ל-Base44 storage → 27 URLs ציבוריים במערך PAGE_IMAGES (לפי הסדר!)
        │
        ▼
Deno function (jspdf@4.0.0):
  לכל עמוד i:  doc.addImage(jpeg, 0,0, 210,297)   ← רקע מלא A4
               אם i הוא עמוד דינמי → לצייר מעל רק את נתוני הלקוח
        │
        ▼
doc.output('arraybuffer') → UploadFile → file_url
```

**עיקרון מנחה:** רק נתונים שמשתנים בין לקוחות מצוירים ב-overlay (שם, ת"ז, כתובת,
מחירים, ✓ דינמיים). כל טקסט קבוע (כותרות, תיאורי חבילות סטנדרטיים) **צרוב בתוך
ה-JPEG** — אל תצייר אותו שוב, זה רק יוצר כפילויות.

## 7 הלקחים הקריטיים (כל אחד עלה בזמן ניפוי)

### 1. RTL ב-jsPDF — להחליף R2L פר-מחרוזת
jsPDF הופך מחרוזת **עברית** כש-`setR2L(false)`, והופך מחרוזת **LTR טהורה**
(מספר/טלפון/מייל/תאריך) כש-`setR2L(true)`. הפתרון: עוטף `put()` שמדליק R2L רק אם
יש תו עברי במחרוזת. אין צורך בספריית bidi.
```ts
const HEB = /[֐-׿]/;
const put = (txt, x, y, align, size) => {
  const t = String(txt ?? ''); if (!t) return;
  doc.setFontSize(size);
  const rtl = HEB.test(t);
  doc.setR2L(rtl);
  doc.text(rtl ? fixRtl(t) : t, x, y, { align });
  doc.setR2L(false);
};
```

### 2. סוגריים הפוכים → מראת סוגריים ידנית
jsPDF לא "ממראה" תווי פיסוק זוגיים תחת R2L, אז `(...)` בתוך עברית מופיע הפוך.
מחליפים כל זוג לפני ההדפסה (רק במחרוזות עברית):
```ts
const MIRROR = { '(' :')',')':'(','[':']',']':'[','{':'}','}':'{','<':'>','>':'<' };
const fixRtl = (s) => s.replace(/[()\[\]{}<>]/g, c => MIRROR[c] ?? c);
```

### 3. ✓ אין ב-Heebo → לצייר כוקטור
פונט Heebo (וגם רוב הפונטים העבריים) חסר את הגליף U+2713. במקום להדפיס תו,
מציירים וי בשני קווים:
```ts
const drawCheck = (cx, cy) => {
  doc.setDrawColor(40,40,40); doc.setLineWidth(0.6);
  doc.line(cx-2, cy-0.2, cx-0.6, cy+1.5);
  doc.line(cx-0.6, cy+1.5, cx+2.4, cy-2.4);
};
```

### 4. טעינת פונט TTF בזמן ריצה
גישת ה-CSS subset של Google Fonts לא מחזירה `.ttf`. למשוך את ה-TTF המלא ישירות
מ-GitHub, להמיר ל-base64, `addFileToVFS`+`addFont`+`setFont`. המרת base64 חייבת
להיות ב-chunks (0x8000) אחרת `String.fromCharCode(...buf)` קורס על קבצים גדולים.

### 5. כיול קואורדינטות = מדידת פיקסלים, לא ניחוש 🔑
**אל תנחש קואורדינטות מצילום מסך.** השיטה המדויקת:
```python
# א. מדוד מרכזי תאים אפורים מתמונת הרקע הגולמית (PIL):
gray = (mx-mn<18)&(mx>120)&(mx<185)         # מסכת התא האפור
#    מצא רצועות עמודות/שורות → מרכז_px → mm = px/width*210
# ב. ודא איפה ה-overlay נחת בפועל: diff בין PDF מרונדר (pdftoppm) לרקע הגולמי:
overlay = abs(raw - rendered).sum(axis=2) > 60
#    centroid של פיקסלי ה-diff = המיקום בפועל → השווה למרכז התא
```
המרה: `mm = פיקסל / רוחב_תמונה * 210`. כך מתקנים סטייה של 1mm במקום 5 סבבי ניסוי.

### 6. כל עמוד Canva הוא רשת נפרדת — אל תשתף קואורדינטות
מלכודת אמיתית: עמוד ההשוואה (p-15) ועמוד המחירים (p-16) נראים זהים אבל הרשת של
p-15 צרה ב-~8mm ומוסטת שמאלה. שימוש באותם `COL_X` לשניהם → טקסט 7-11mm מחוץ
למרכז. **מדוד כל עמוד דינמי בנפרד.**

### 7. Base44: workspace מול Published 🔑
- העורך שומר ל-**workspace** (dev). האפליקציה החיה מריצה את גרסת ה-**Published**.
- שמירה/deploy בלבד **לא** מספיקה — חובה ללחוץ **Publish** (כפתור כתום).
- `file_url` שמשתנה **לא** מוכיח שקוד חדש רץ (גם הקוד הישן מעלה קובץ חדש כל פעם).
- אחרי Publish צריך **לייצר מחדש** (Publish לא מרענן PDFים קיימים).
- טריק אבחון: חותמת זמנית (`put('v4', 8,8,...)`) בפינה — אם היא מופיעה, הקוד החדש רץ.

## מלכודת הדבקה: עברית בתוך קוד נשברת
כשהמשתמש מדביק קוד עם תווים עבריים בתוך הקוד (regex `/[֐-׿]/`, מחרוזת `'כן'`,
הערות) — bidi/העתקה משבשת תווים והקומפיילר נופל. פתרונות:
1. להשתמש ב-escapes יוניקוד: `/[֐-׿]/` במקום תווים עבריים.
2. להעדיף **שינוי דרך ה-Builder** (הודעה ממוקדת) על פני הדבקת קובץ שלם.
3. אם בכל זאת מדביקים — קובץ ASCII-נקי (הערות באנגלית, מחרוזות עבריות ב-`\u`).

## API של Base44 (Deno function)
```ts
import { createClientFromRequest } from 'npm:@base44/sdk@0.8.25';
const base44 = createClientFromRequest(req);
const user = await base44.auth.me();                       // auth
await base44.asServiceRole.entities.Client.filter({ id }); // קריאת נתונים
await base44.asServiceRole.integrations.Core.UploadFile({ file }); // → { file_url }
```
טעינת 27 תמונות **סדרתית** עם לוג פר-תמונה (טעינה מקבילית מפילה את ה-burst
הראשון → עמודים ריקים). בדיקה קשיחה `PAGE_IMAGES.length === 27`.
